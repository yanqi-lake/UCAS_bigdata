# 个贷违约预测：实验结果记录（论文素材，非最终论文）

本记录只整理已经实际运行的结果。原始数据和固定切分均未修改。所有模型开发、特征方案比较、PCA 比较和阈值选择均使用 `train_public.csv` 的 8,000 条开发样本；2,000 条留出样本仅在最终方案固定后评价一次。`train_internet.csv` 和 `test_public.csv` 未用于以下指标。

## 1. 数据与切分

- 数据：`data/train_public.csv`，10,000 行、39 列，SHA256：`797ee36cf3e610413c015c763a37582121a2fb5cb2c4d22ff8fa48524693e0e7`。
- 固定分层切分：开发集 8,000 条、留出集 2,000 条；开发集内五折交叉验证，种子 2026。切分文件：`data/splits/split_indices.json`。
- 开发集违约标签为 1 的样本共 1,346 条，占 16.825%；留出集标签为 1 的样本共 337 条。
- 开发集缺失率较高的字段包括 `f1`（8.675%）和 `work_year`（6.150%）。

## 2. 课程模型与全部特征基线

预处理包括数值字段中位数填补、标准化、类别字段众数填补与独热编码。所有填补器、编码器和标准化器只在每折训练样本上拟合。

| 模型 | 五折平均 ROC-AUC | 阈值 0.5 的五折平均 F1 |
| --- | ---: | ---: |
| 逻辑回归 | 0.8588 | 0.4052 |
| 决策树 | 0.8423 | 0.4610 |
| 随机森林 | 0.8757 | 0.1642 |

全部特征的阈值探索中，随机森林在阈值 0.275 时的平均 F1 为 0.5879。这个阈值和得分均来自开发集，不能当作独立测试结果。

## 3. 特征可用性敏感性

`early_return`、`early_return_amount`、`early_return_amount_3mon` 与标签相关性较高。为评估模型对它们的依赖，在同一五折与同一模型参数下排除三个字段：

| 模型 | 全部特征 AUC | 排除三个字段后的 AUC |
| --- | ---: | ---: |
| 逻辑回归 | 0.8588 | 0.6829 |
| 决策树 | 0.8423 | 0.6135 |
| 随机森林 | 0.8757 | 0.6848 |

这一结果说明三个字段提供很强的预测信息，但不能单凭性能差异判定数据泄漏。若研究问题是贷款发放前的违约风险预测，需要进一步确认这些字段在该时点是否可获得。后续评价采用排除这三个字段的保守方案。

## 4. PCA 对照

仅对数值字段进行中位数填补、标准化和 PCA；类别独热编码字段不参与 PCA。PCA 在每折训练集内拟合，以累计解释方差不少于 95% 为准。数值预处理输出由 24 维压缩至 15 维，五折平均累计解释方差为 95.11%。

| 模型 | 不使用 PCA 的五折平均 AUC | 使用 PCA 的五折平均 AUC |
| --- | ---: | ---: |
| 逻辑回归 | 0.6829 | 0.6815 |
| 决策树 | 0.6135 | 0.6317 |
| 随机森林 | 0.6848 | 0.6793 |

PCA 对决策树略有帮助，对另外两个模型没有提升。保留 PCA 实验以展示降维方法与模型效果之间的关系；最终方案按预先记录的开发集平均 AUC 规则选择不使用 PCA 的随机森林。

## 5. 开发集阈值选择与固定方案

先根据开发集五折平均 ROC-AUC 在六个模型方案中选模型；再在 0.05 至 0.50、步长 0.005 的固定网格上选平均五折 F1 最高的阈值。选择过程与结果保存在 `results/reduced_model_decision_20261126T185314Z.json`。

固定方案：排除三个 `early_return` 字段；不使用 PCA；随机森林（200 棵树，最大深度 12，叶节点最少 10 个样本，随机种子 2026）；阈值 0.19。该方案开发集五折平均 ROC-AUC 为 0.6848，在所选阈值下平均 F1 为 0.3692。选择阈值所用的开发集 F1 存在选择偏差，应以留出集结果作为独立评价。

## 6. 一次性留出集评价

固定上述方案后，用全部 8,000 条开发样本重新拟合，并对 2,000 条留出样本预测一次：

| 指标 | 留出集结果 |
| --- | ---: |
| ROC-AUC | 0.6794 |
| Average Precision | 0.3018 |
| F1 | 0.3733 |
| Precision | 0.2716 |
| Recall | 0.5964 |

混淆矩阵：TN = 1124，FP = 539，FN = 136，TP = 201。这里的 Precision 与 Recall 体现了固定阈值 0.19 下的取舍，不能只按其中一个指标评价模型。

随机森林的训练后不纯度特征重要性中，排序靠前的转换后字段包括 `interest`（0.1198）、`debt_loan_ratio`（0.0639）、`recircle_b`（0.0492）、`known_outstanding_loan`（0.0480）和 `recircle_u`（0.0463）。这种重要性是模型内部的描述性指标，不代表因果关系。
